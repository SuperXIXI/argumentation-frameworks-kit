渐进式语义

当前框架已初始化。可以拖拽节点，也可以直接单步迭代。
语义公式 
对每个目标节点 a，在第 t 轮使用上一轮强度 s(t) 同步计算：

Sup_a = 1 - Π(1 - w_ba * s_b(t))，b 为支持 a 的节点
Att_a = 1 - Π(1 - w_ca * s_c(t))，c 为攻击 a 的节点
Δ_a = Sup_a - Att_a

若 Δ_a >= 0:
  F_a = τ_a + (1 - τ_a) * Δ_a
若 Δ_a < 0:
  F_a = τ_a + τ_a * Δ_a

s_a(t+1) = s_a(t) + η * (F_a - s_a(t))
当 max |s_a(t+1)-s_a(t)| < ε 时停止。
